## 问题记录

### BUG-001：草稿任务无法通过聊天修改，且存在重复确认

#### 复现步骤
1. 生成计划草稿，暂不确认。
2. 在聊天中输入“最后3个任务改一下”。
3. 补充“都替换掉”“替换”。

#### 预期结果
助手根据当前目标替换最后3个任务。
其余任务、日期和顺序保持不变，保存后仍为草稿状态。
没有指定替换方向时，可根据目标合理安排，不重复要求确认。

#### 实际结果
助手多次要求用户确认替换方向。
随后提示只能基于已确认的正式计划修改，
要求用户先确认原草稿，未完成任务替换。

#### 原因分析
1. 协调Agent缺少明确的草稿修改工具与交互规则。
2. 现有计划调整服务仅允许正式计划作为修改来源，
   未覆盖“确认前修改草稿”的场景。

#### 修复方案
1. 增加update_draft_tasks工具。
2. 校验会话归属和草稿状态，只修改指定任务的标题与预期产出。
3. 使用数据库事务保存，保留其他任务、日期和顺序。
4. 调整提示词，明确授权后直接执行，保存成功后才报告完成。

#### 复测检查
- [ ] 草稿无需先确认即可修改。
- [ ] 只修改指定的最后3个任务。
- [ ] 其余任务、日期和顺序不变。
- [ ] 刷新后修改仍保留。
- [ ] 修改后的草稿可以正常确认生效。
