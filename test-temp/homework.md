# 基于 DeepSeek 与 LangChain 的 IMDb 电影评论自动情感标注实验

## 1. 数据集与任务描述
数据集选用 Hugging Face 平台提供的 **IMDb 电影评论数据集**（`stanfordnlp/imdb`）。该数据集包含电影评论文本及对应的人工情感标签。

**数据集来源：** [IMDb Movie Reviews — Hugging Face](https://huggingface.co/datasets/stanfordnlp/imdb)

本实验从测试集中选取 100 条评论，其中正面评论 50 条、负面评论 50 条。

- **输入特征：** 英文电影评论文本。
- **标注目标：** 二分类情感识别。
- **标签定义：** `0` 表示负面（Negative），`1` 表示正面（Positive）。
- **实验目标：** 使用大语言模型自动生成情感标签，并与数据集原有的人工标签进行比较，评估模型的自动标注能力。

## 2. 模型与方法

### 2.1 模型选择

本实验采用 **DeepSeek-Flash** 大语言模型，通过兼容 OpenAI API 的接口进行远程调用，并使用 LangChain 框架构建自动标注流程。

### 2.2 自动标注流程

整个标注流程主要包括三个部分：

1. **ChatPromptTemplate：** 构建情感分类提示词，将电影评论插入指定的输入模板。
2. **DeepSeek-Flash：** 理解评论内容并判断整体情感倾向。
3. **StrOutputParser：** 将模型返回的消息解析为字符串，再转换成数值标签。

通过 LangChain 的管道操作符 `|`，将三个组件连接为完整的处理链：

```python
chain = prompt | model | StrOutputParser()
```

模型输出的 `positive` 转换为标签 `1`，`negative` 转换为标签 `0`。

### 2.3 Prompt 设计

本实验采用零样本提示（Zero-shot Prompting），即不向模型提供额外的已标注示例，而是直接描述任务及输出要求。

核心提示词如下：

> You are a professional movie review sentiment classifier.
>
> Your task is to classify a movie review into one of two categories:
>
> positive
>
> negative
>
> Rules:
>
> 1. Consider the overall sentiment of the review.
> 2. Return only one word: positive or negative.
> 3. Do not provide explanations.

这种设计能够约束模型的输出格式，减少无关文本对自动标注程序的影响。

## 3. 代码实现与实验结果

### 3.1 代码实现

本实验使用 Python 实现自动标注程序，主要依赖 Pandas、LangChain 和 scikit-learn。

程序首先使用 Pandas 读取 `imdb_100.csv`，然后逐条调用 DeepSeek-Flash 生成预测标签，并将结果保存至 `labeling_results.csv`。

核心代码如下：

```python

chain = prompt | model | StrOutputParser()

# 模型预测
def predict_sentiment(text: str) -> int:
    result = chain.invoke({"review": text})
    result = result.strip().lower()

    if result == "positive":
        return 1
    elif result == "negative":
        return 0
    else:
        raise ValueError(f"Invalid output: {result}")
```

程序还实现了中间结果保存、已标注样本跳过、异常处理和分类指标计算等功能，能够降低 API 调用失败导致的数据丢失风险。

### 3.2 实验结果

本实验共处理 100 条电影评论，模型成功完成全部样本的自动标注。

| 评价指标 | 实验结果 |
|---|---:|
| 总样本数量 | 100 |
| 正面评论数量 | 50 |
| 负面评论数量 | 50 |
| 正确标注数量 | 95 |
| 错误标注数量 | 5 |
| 准确率（Accuracy） | **95.00%** |

实验得到的混淆矩阵如下：

| 人工标签 | 模型预测为负面 | 模型预测为正面 |
|---|---:|---:|
| 负面（Negative） | 47 | 3 |
| 正面（Positive） | 2 | 48 |

其中，50 条负面评论中有 47 条预测正确，3 条被错误预测为正面；50 条正面评论中有 48 条预测正确，2 条被错误预测为负面。

准确率计算公式为：

\[
Accuracy = \frac{\text{正确预测数量}}{\text{总样本数量}}
\]

因此：

\[
Accuracy = \frac{95}{100} = 95\%
\]

## 4. 实验结果分析

实验结果表明，DeepSeek-Flash 在未进行额外训练的情况下，能够较准确地识别 IMDb 电影评论的整体情感倾向，100 条样本的分类准确率达到 95%。

**模型表现较好的情况：**

对于情感倾向明确、评价内容相对直接的电影评论，模型通常能够正确识别其正面或负面情感。大语言模型不仅能够识别情感关键词，还能够结合上下文理解评论的整体含义。

**模型可能出现错误的情况：**

1. **混合情感：** 一条评论同时包含赞扬和批评时，模型可能难以判断整体情感。
2. **讽刺与反语：** 评论的字面意思与实际情感相反时，模型可能产生误判。
3. **长文本评论：** 评论包含多个观点或复杂情节描述时，模型可能受到局部情感表达的干扰。
4. **主观性较强的评论：** 某些评价缺少明确情感倾向，不同标注者可能给出不同结果。

需要说明的是，上述情况属于对潜在错误原因的分析，并不意味着本次实验中的五条错误样本已经逐一验证属于这些类别。

总体而言，大语言模型能够有效完成多数情感分类任务，但对于存在歧义或复杂语义的文本，仍需要进一步验证。

## 5. 人工标注与模型标注的比较

| 比较维度 | 人工标注 | 大语言模型标注 |
|---|---|---|
| 标注速度 | 相对较慢 | 自动化程度高，适合批量处理 |
| 标注成本 | 大规模标注需要较多人力 | 主要产生 API 调用费用 |
| 标注一致性 | 可能受到不同标注者主观判断影响 | 固定提示词下通常具有较好的一致性 |
| 语义理解 | 擅长结合背景知识和语境判断 | 具有较强语义理解能力，但可能误判 |
| 扩展能力 | 扩大规模需要增加人员 | 易于扩展至大量样本 |
| 偏差问题 | 可能存在个人认知偏差 | 可能受到训练数据及模型自身偏差影响 |

人工标注的主要优势在于能够结合上下文和专业知识，对复杂或存在歧义的样本作出判断。但在大规模数据集上，人工标注需要投入较多时间和成本。

大语言模型标注具有自动化程度高、可扩展性强等优势，适合快速生成初始标签。然而，模型预测并非完全准确，且可能受到提示词设计、模型能力及训练数据偏差的影响。

因此，将模型自动标注与人工抽查、复核相结合，是一种兼顾效率与标注质量的可行方案。

## 6. 改进方案
### 6.1人机协同标注（Human-in-the-Loop）

这个我觉得是当下最现实的改进方案。可以将模型自动标注作为第一阶段，再针对模型预测不一致、语义复杂或置信度较低的样本安排人工复核。通过优先检查困难样本，能够减少人工工作量，同时提升最终数据集的可靠性。
这个方案在保证准确率的前提下可以极大的减少人工成本，也可以使用较小的模型节省算力资源。

### 6.2 少样本提示

当前实验采用零样本提示，模型仅根据任务说明完成分类。
后续可以在 Prompt 中加入若干具有代表性的正面、负面及复杂情感评论示例，让模型学习更明确的判断标准。
这种方法有望提高模型对复杂情感表达的识别能力，并进一步规范输出格式。
### 6.3 多模型投票
可以同时使用 DeepSeek、Qwen 等不同大语言模型对同一条评论进行标注，并综合多个模型的预测结果。当多个模型给出一致标签时，可以提高对该结果的信任程度；当模型之间存在分歧时，则将对应样本标记为需要进一步检查。
该方法有望减少单一模型的偶然性错误，但也会增加推理成本。

## 7. 总结
​	本项目基于 IMDb 电影评论数据集，使用 DeepSeek-Flash 大语言模型和 LangChain 框架，实现了电影评论情感的自动标注。实验共处理 100 条评论，其中 95 条预测正确，整体准确率达到 **95%**。实验结果说明，大语言模型无需针对特定任务进行额外训练，即可利用自然语言提示完成具有较高准确率的情感分类任务，体现了基础模型在自动数据标注领域的应用潜力。同时，实验也表明模型标注仍存在一定误差。未来可以通过少样本提示、多模型投票和人机协同复核等方法进一步提升标注质量。
